# Build a controlled harness comparison benchmark

Implement evaluation infrastructure in this repository. Follow the hardening
README. The predecessor at `~/Projects/craft` remains read-only.

## Problem

Architecture and test counts do not establish coding quality, token savings,
latency or operational safety. No paid-model comparison was run in the audit.

## Work

Define reproducible tasks with fixed starting commits, model settings and success
criteria: bug fix, multi-file refactor, large-repo exploration, long headless
compaction, parallel worktrees, permission/sandbox failures, resume and ACP media.
Record task success, unintended changes, token/cost totals, elapsed time, retries
and compaction information loss. Separate deterministic safety tests from
stochastic model trials and account for repeated-run variability.

## Acceptance

- Provide fixtures, runner instructions, result schema and comparison rubric.
- Do not modify the reference checkout; use approved disposable environments.
- No secrets or private transcript contents enter committed results.
- Obtain approval for paid runs and explicit cost/time ceilings.
- Report measurements separately from hypotheses and recommend adjustments.
