craft

the context-thrifty coding agent

A terminal coding agent written from scratch in Rust on the animist stack. Tool output is pre-compressed, stale reads collapse to durable markers, and compaction is staged and reversible — so tokens go to your task, not to stale history. Subagents, MCP, in-process knowledge, nine provider kinds including local models.

Context efficiencyWhere tokens go

pre-compression

Every tool result is classified — code, log, diff, JSON, search — and rewritten into a compact marker before it enters history. The verbatim original stays on the entry; retrieve restores it by hash in any later turn, even after a reload.

read lifecycle

Reads go stale as the conversation moves on. Stale and superseded reads collapse into durable marker revisions, so old file snapshots stop occupying the window — without losing a byte.

staged compaction

Deterministic vcc at 60% of the window, one LLM summary at 80%. Stages that wouldn't save ≥10% are skipped, compacted entries are deactivated — never deleted — and an overflow ladder collapses tool results before a turn ever fails.

subagents

The task tool runs children in their own context windows with weak / medium / strong model tiers, restricted tool tables, and optional worktree isolation. batch fans them out concurrently. Delegation never pollutes the main session.

The harnessWhat you get

one harness, every surface

TUI, --print, and ACP all drive the same long-lived Conversation: permission, guardrail, request-shaping, recovery, continuation, snapshot, and persistence layers — in that order, for every turn, on every surface.

recovery that holds

Streaming retries with backoff, API-key rotation, model fallback chains, doom-loop detection with hard stops, and per-tool guardrails that demote failing tools. A turn survives a lot before it gives up.

permissions that see through pipes

Bash is parsed with tree-sitter, so git diff && rm -rf / asks for git * and rm * separately. Headless runs fail closed. Writes are snapshotted for /undo, and bash runs under an OS sandbox. --yolo when you mean it.

argosy knowledge

Semantic search and ask, review sessions with P0–P3 findings, skills, and post-turn memory extraction — all in-process with local ONNX embeddings. No subprocess, no MCP round trip.

the harness: policy in layers

One long-lived Conversation per session drives an animist Agent. Craft policy lives in an ordered layer chain — head to tail — and runs once for every surface.

PolicyLayer

permission rules → auto-review → the approval responder → the plan-mode gate.

GuardrailLayer

doom-loop detection (grace / hard-stop), per-tool guardrails, dedup respond.

RequestLayer

the per-request view: read-lifecycle and compression rewrites, image relocation, output-token clamp, fallback-model selection.

RecoveryLayer

linear backoff, API-key rotation, model fallback chain, reauth wait, overflow compaction.

ContinuationLayer

MaxTokens continuation and stalled-turn nudges as step_end appends.

SnapshotLayer

/undo pre-captures at the tail — only calls that really run get captured.

PersistLayer

flushes the history change feed to the crash-safe session log.

requests flow down · events flow up · subagents get their own stack
