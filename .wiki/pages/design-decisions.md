# Design Decisions

Conventions, patterns, and rationale distilled from `AGENTS.md`, `CONTRIBUTING.md`, `justfile`, CI configs, and source practice.

## Code style (`AGENTS.md:5-30`)

- No trivial comments. Comments explain WHY, not WHAT (`CONTRIBUTING.md:18`).
- Minimal bloat: KISS, DRY, SRP. No unnecessary state. Each line justifies itself.
- No wildcard imports. Import types at the top of a file and use short names inline (`use std::sync::Arc;` then `Arc<T>`).
- Latest Rust features are allowed (edition 2024).
- Descriptive names. Keep consts at the top of a file, right after imports.
- `#[derive(Copy)]` only on structs with a single primitive field.
- No inline magic numbers or strings.

## Error handling (`AGENTS.md:15-17`, `craft-providers/src/error.rs`)

- Explicit `Result<T, E>` over panics.
- `color_eyre` when the specific error variant does not matter.
- `thiserror` for domain errors. Domain types carry structured fields (e.g. `Api { status, message }`), `#[from]` conversions, and helper methods like `is_retryable()`, `is_auth_error()`, `user_message()`.
- Error messages must be helpful.

## Testing (`AGENTS.md:18-28`, `justfile:10-14`, `.config/nextest.toml`)

- cargo-nextest is the test runner. Command: `cargo nextest run --all-features --workspace`.
- Clippy gate: `cargo clippy --all-features --all --tests -- -D warnings`.
- Unit tests live in the same file under `#[cfg(test)]`.
- Parameterized tests use `#[test_case]` with snake_case names; assert against shared `const` error/status strings.
- No tautology tests. Tests must not depend on sleeps or machine speed.
- Nextest config: `fail-fast = false`, `test-threads = 64`.

## Logging (`AGENTS.md:23`, `craft-ui/src/app/mod.rs`)

- Prefer structured logging with wide fields: `tracing::warn!(%warning, "keybinding config")`.
- tracing-subscriber with `std`, `fmt`, `env-filter`, `json` features (`Cargo.toml:102-103`).

## Dependency policy (`AGENTS.md:19-21`)

- Add deps to the global `[workspace.dependencies]` in the root `Cargo.toml`; reference as `{ workspace = true }` in per-crate manifests.
- Solve with existing deps before adding new ones.
- Prefer well-maintained crates from crates.io.

## Performance

- Be mindful of allocations in hot paths (`AGENTS.md:22`).

## Runtime choices (`README.md`)

- tokio for async (migrated from smol).
- reqwest for HTTP (migrated from isahc).
- flume for async channels.

## CI (`justfile:37-38`, `.github/workflows/rust.yml`)

- Full CI: fmt-check, lint, pylint, test, gen-docs-check.
- cargo-machete for unused dependency detection.
- Lua formatted with stylua.
- Windows cross-platform lint and build checks.

## Docs (`AGENTS.md:61-65`)

- User docs in `site/docs/`, mostly generated by `craft-docgen` via `just gen-docs`.
- Tone: warm, simple, concise, story-telling. No em-dashes, no emojis, no AI tone.

## Refactor note (`CONTRIBUTING.md:4`)

- Heavy refactor ongoing for the Lua plugin system. Prefer small changes and bug fixes over large features.
